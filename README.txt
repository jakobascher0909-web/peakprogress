PeakProgress – Fitness & Ski Tracker

GitHub Pages setup:
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open Settings > Pages.
3. Under Build and deployment choose Deploy from a branch.
4. Choose branch main and folder /(root), then Save.
5. Wait for the Pages URL to appear.

The app stores data locally in the browser. Export a JSON backup from the app regularly. Data is not automatically synchronized between devices.
For PWA installation, serve over HTTPS (for example GitHub Pages).
