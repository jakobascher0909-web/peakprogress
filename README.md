# PeakProgress
Persönlicher Fitness-Tracker als Web-App (PWA) mit 52-Wochen-Jahresplan.

- Wochen folgen automatisch dem Kalender (Start = Montag der ersten Nutzung)
- Jeder Wochentag hat ein eigenes Programm (Mo–Sa Training, So aktive Erholung)
- Geräte: Laufband, Rudergerät, Crosstrainer (optional), Kurzhanteln, Körpergewicht
- Eigener Bereich für das Gewichtsprotokoll
- Daten bleiben lokal im Browser (localStorage), Backup per JSON-Export

Installation (GitHub Pages): alle Dateien im Repository-Hauptverzeichnis ersetzen
(index.html, sw.js, manifest.json, Icons), committen, dann mit Strg+F5 neu laden.
